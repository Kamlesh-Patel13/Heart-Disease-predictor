# 🫀 Heart Disease Prediction

A full-stack Machine Learning web application that predicts the likelihood of heart disease based on user-provided health parameters.

## 🚀 Tech Stack

- Frontend: React.js
- Backend: FastAPI
- Machine Learning: K-Nearest Neighbors (KNN)
- Language: Python
- API Communication: REST API
